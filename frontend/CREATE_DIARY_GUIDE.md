# ✍️ 发布日记功能使用指南

## 🎯 功能说明

新增了完整的日记发布功能，用户可以：
- ✅ 编写标题和正文内容
- ✅ 上传最多9张图片
- ✅ 选择关联景点（可选）
- ✅ 实时预览上传的图片
- ✅ 发布后自动刷新列表

## 🚀 使用步骤

### 1️⃣ 登录账号
```
必须先登录才能看到"发布日记"按钮
未登录用户只能查看，不能发布
```

### 2️⃣ 打开发布界面
```
点击日记列表页右上角的 "✍️ 发布日记" 按钮
```

### 3️⃣ 填写内容
| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 标题 | ✅ 必填 | 最多100字 |
| 景点 | 可选 | 从下拉列表选择 |
| 正文 | ✅ 必填 | 最多5000字 |
| 图片 | 可选 | 最多9张，单张≤5MB |

### 4️⃣ 上传图片
```
1. 点击 📷 上传按钮
2. 选择1-9张图片（支持多选）
3. 等待上传完成（自动显示预览）
4. 点击预览图右上角 ✕ 可删除
```

### 5️⃣ 发布
```
点击 "发布日记" 按钮
→ 后端保存到数据库
→ 列表自动刷新
→ 新日记出现在顶部
```

## 🔧 技术实现

### 前端组件
| 文件 | 说明 |
|------|------|
| `CreateDiaryModal.vue` | 发布日记模态框（新创建）|
| `DiaryPanel.vue` | 集成发布按钮和模态框 |

### 后端接口
| 接口 | 方法 | 说明 |
|------|------|------|
| `/upload` | POST | 上传图片，返回URL |
| `/diaries/` | POST | 创建日记 |

### 数据流
```
用户选择图片
  ↓
前端调用 /upload 接口
  ↓
后端保存到 uploads/ 目录
  ↓
返回 URL: /uploads/xxx.jpg
  ↓
前端收集所有 URL
  ↓
提交到 /diaries/ 创建日记
  ↓
后端将 URL 数组转为 JSON 存入 media_json
  ↓
保存到数据库
```

## 🐛 常见问题

### Q1: 点击"发布日记"没反应
**原因:** 未登录
**解决:** 先点击右上角登录

### Q2: 图片上传失败
**原因:** 
1. 文件过大（>5MB）
2. 格式不支持（非JPG/PNG/GIF）
3. 后端服务未启动

**解决:**
```bash
# 检查后端是否运行
uv run src/api.py

# 压缩大图片
使用在线工具：tinypng.com
```

### Q3: 发布后看不到新日记
**原因:** 可能在第2页
**解决:** 
1. 点击"刷新"按钮
2. 切换排序为"最新发布"

### Q4: 上传的图片显示不了
**原因:** URL路径问题
**解决:**
```javascript
// 检查浏览器控制台
// 确认图片URL格式：
http://localhost:8000/uploads/xxx.jpg
```
